# CourseSprout API Credentials

## API Key

Get your API key from CourseSprout dashboard:
1. Log into https://app.coursesprout.com
2. Go to Settings > API Access
3. Generate/copy API key

## Setup

**Option 1: Environment Variable (Recommended)**
```powershell
$env:COURSESPROUT_API_KEY = "your_api_key_here"
```

**Option 2: Credentials File**
Create `credentials/coursesprout.txt`:
```
API_KEY: your_api_key_here
```

## Authentication

All API requests require the X-API-KEY header.

**Base URL:** https://api.coursesprout.com/api/ai

**Test connection:**
Ask OpenClaw: "Test my CourseSprout API connection"

## Security

⚠️ Never commit API keys to version control
⚠️ Keep credentials file in .gitignore
⚠️ Use environment variables for production

## Troubleshooting

**401 Unauthorized:**
- Check API key is set correctly
- Verify key hasn't expired
- Confirm key from correct account

**API Key missing:**
- Set environment variable
- Or create credentials file
- Restart OpenClaw if needed
